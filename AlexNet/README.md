## 使用$AlexNet$实现猫狗分类
原论文采用两个GPU并行的方式进行训练，在现在GPU算力和显存足够的情况下，选择了使用一个GPU进行计算。


尝试调整了学习率，但效果几乎没有，训练十几个epoch，准确率维持在50%左右。

调整batch_size为128；调整网络结构，将LRN(归一化)调整到激活函数前，训练几个epoch可以看到Loss在每一个epoch逐步减少，准确率也在慢慢提高。

训练到第28个epoch，loss为0.1208，acc为95.41%，不知道是不是过拟合了。

<p align="right">2025.9.16</p>

重新训练了一遍，在第14轮在测试集上准确率达到79.54%，最高值；第19轮达到79.12%，训练过程中准确率一直在77%~80%之间波动。

使用BatchNorm替换LRN，在每一个卷积后都进行BN归一化，可以看到收敛速度远快于LRN，准确率也大幅提高，一共训练了26轮，验证集上最高准确率达到了91.26%。
