# GoogLeNet

本项目主要是根据GoogLeNet原论文实现了GoogLeNet的网络架构。

使用25000张猫狗图片对GoogLeNet进行训练，其中20000张为训练集，5000张验证集。训练后的数据将最优模型和最后的模型保存到model文件夹下。同时绘制每一轮的Loss和Accuracy也保存到相同的文件夹下。

第一次训练了3轮进行测试程序是否能正常运行；第二次测试运行了20轮，在训练集上Loss稳定减小，Accuracy稳步提升。在验证集上，Loss和Accuracy在刚开始训练的几轮中有震荡，在总体趋势是减少/增加的。在验证集合第12轮，Accuracy最优达到94.94%。此后验证集上准确率在88%~94%之间震荡，猜测此时可能学习率过大了，可以减小学习率继续训练。

学习率降低至0.0005，再次训练20个epoch，验证集上Loss在[0.15, 0.35]之间，Acc在[0.94, 0.96]之间。但在20轮中还是存在小幅度震荡。再跑了20轮效果不明显。
